Evaluating the trip parser

The only AI in Fair Fare turns a typed trip ("Billyburg to LGA, Sunday 7am") into two NYC taxi zones, a time band and a day type. This page scores it next to a no-AI keyword baseline, using the exact prompt and model the live tool uses (), on two sets:

  • Golden set (40): written alongside the prompt. Good for catching regressions, too friendly to prove much on its own.
  • Held-out stress set (30): written after parse-v1 was frozen and never used to tune it: typos, texting shorthand, decoy times, multi-stop trips, places outside NYC, and questions that aren't trips at all.
  • Route accuracy: both zones correct, on the cases that name two real NYC places.
  • Refusal accuracy: returns no route when the text has no NYC trip at all, so the tool never invents one.
  • No false precision: leaves a side empty when it names only a borough or a place outside NYC.
  • Time and day accuracy: correct band and weekday/weekend, including leaving them empty when none is given.
  • Invalid zone ids: ids that don't exist, counted as hallucinations.
